# Actor 转蓝图 · 建筑蓝图创建器

将 Unreal Engine 关卡中的多个 Actor 整理成可重复使用的建筑蓝图，保留模型、材质与空间关系。

当前版本：**1.9.3**。面向 **Unreal Engine 5.6.1 / Windows 编辑器**。

## 主要功能

- **Actor 转蓝图**：选择静态网格体 Actor、已有蓝图 Actor、原生组或空父节点，创建建筑蓝图；可包含全部挂接子级，并选择是否替换关卡中的原对象。
- **按父级批量创建**：按父级分别生成建筑蓝图，显示成功、失败详情与完整报告。
- **重复模型转为 ISM**：将兼容的重复模型实例化，保留不适合归组的零件。
- **Nanite 与已有建筑优化**：可开启引用模型的 Nanite，支持对已有建筑蓝图批量优化、另存副本或备份后替换。
- **使用辅助**：建筑缩略图、世界大纲显示、设置记忆、备份管理和内存记录。

普通创建保留独立零件，不合并模型；启用 ISM 时，兼容的重复零件改用实例化表示。模型、材质继续引用项目中的原资源。

## 安装

本仓库为源码版，不包含预编译 DLL、UE 引擎代码或项目素材。

1. 下载仓库，将根目录文件放入 `<项目目录>/Plugins/BuildingBlueprintCreator/`，确保该目录下能直接看到 `BuildingBlueprintCreator.uplugin` 和 `Source`。
2. 使用配置好 Unreal C++ 编译环境的 UE 5.6.1 工程，生成项目文件并编译 Editor 目标；或打开工程并按提示编译插件。
3. 在插件管理器中确认启用 **Building Blueprint Creator**。插件声明了 **Datasmith Content** 依赖。
4. 重新打开编辑器。其他引擎版本需要自行编译并验证兼容性。

## 快速使用

1. 在世界大纲中选择建筑的 Actor。
2. 右键选择 **创建蓝图 Actor…**（位于“世界分区”区域下方）。
3. 输入名称并选择 `/Game` 中的保存目录。
4. 按需设置包含子 Actor、替换原 Actor、ISM 和 Nanite 选项，再执行创建。
5. 检查生成结果，保存关卡；生成的蓝图可以再次拖入关卡使用。

内容浏览器中选择本插件生成的建筑蓝图，右键 **优化建筑蓝图…**，可对单个或多个蓝图优化。

## 使用前须知

- 源蓝图及模型、材质等依赖应先编译并保存。暂不支持原生灯光、特效等任意 Actor，不能可靠保存的对象或引用会被拒绝。
- 开启 Nanite 会修改并保存引用的原 Static Mesh，影响项目中所有引用该模型的对象；蓝图备份不能回退模型的 Nanite 设置。
- **1.9.3 的优化功能会在每项成功后执行“全部保存”**，包括关卡及其他已修改资源。未命名关卡会弹出保存对话框；取消或保存失败会计为失败，已经生成的优化结果保留。
- 跨工程使用请通过 UE“迁移”功能携带依赖，单独复制蓝图文件不会带走模型和材质。
